# Nick's Excel Writer

一个基于 Python + Tkinter 的 Excel 编辑工具，专为班级量化管理/积分记录场景设计，支持单元格快捷写入、批量加减分、平均值自动计算等功能。

![Python Version](https://img.shields.io/badge/python-3.7%2B-blue)
![License](https://img.shields.io/badge/license-MIT-green)

## 主要功能

- 📂 **拖拽/选择打开 Excel 文件**（支持 `.xlsx` / `.xls`）
- ✍️ **单元格写入**：支持中文姓名自动定位行，支持“属性 + 分数”简写命令
- 🧮 **分数表达式规范化**：自动合并 `+/-` 同类项（如 `100-25-25+2` → `102-50`）
- 📊 **一键填充平均值**：根据指定列范围自动计算每组成员平均分
- 📝 **批量写入**：
    - **离散模式**：每行 `姓名 属性 分数` 独立写入
    - **连续模式**：首行指定姓名和属性，后续每行只写分数，自动向下逐行写入
- 🔄 **实时刷新表格视图**，支持保存
- 🎯 **拼音首字母快速定位姓名**（例如 `cjl` → 罗彦熙）

## 安装与运行

### 1. 环境要求

- Python 3.7 或更高版本
- 已安装 pip

### 2. 安装依赖库

```bash
pip install openpyxl pypinyin tkinterdnd2
```

### | tkinterdnd2 用于拖拽功能，如不需要拖拽可省略，但会提示警告。

### 3.运行程序

```bash
python -m mytool.py
```

## 使用指南

### 界面概览

* 顶部：文件路径输入框 + “选择文件”按钮

* 中间：拖拽区域（支持将 .xlsx/.xls 文件拖入）

* 下方：文件加载后显示 Excel 工作表视图及操作按钮

### 加载文件后

#### ① 写入单个单元格

* 姓名：输入学生姓名（支持中文全名或拼音首字母缩写，如 cjl）

* 内容：输入 属性 分数 或 属性 +/-分数

* 点击 ✓ 写入 即可更新对应单元格

### ② 属性缩写对照表

| 缩写 | 	含义 | 	对应列偏移   |
|----|-----|----------|
| kq | 考勤  | 	考勤	+0   |
| ly | 礼仪  | 	礼仪	+1   |
| jl | 纪律  | 	纪律	+2   |
| zy | 作业  | 	作业	+3   |
| gg | 过关  | 	过关	+4   |
| tz | 拓展  | 	英语拓展	+5 |
| dl | 锻炼  | 	锻炼	+6   |
| hd | 活动  | 	活动	+7   |
| bw | 班务  | 	班务	+8   |
| yy | 英语  | 	英语课堂	+9 |

### ③ 分数输入格式

* 绝对分：ly 100（直接写入 100）

* 加分：jl +50（在原分数上增加 50）

* 减分：kq -10（在原分数上减少 10）

* 支持 / 前缀：zy /5 表示直接覆盖为 5（不进行加减运算）

### ④ 批量写入

#### 点击 ***批量写入*** 按钮，有两种模式：

##### ***离散模式***

每行一条完整记录，例如：

```text
cjl ly +100
lyx jl -50
cyt zy +30
```

##### ***连续模式***

第一行指定起始姓名和属性，后续每行只写分数，从该行向下依次写入：

```text
cjl ly
+100
-50
+30
```

程序会自动找到姓名的 Excel 行号，并向下逐行处理直到遇到空行或无姓名单元格。

### ⑤ 填充平均值

首次打开文件时会弹出窗口要求输入“个人总分列”的起止列字母（例如 C L）。
程序将自动计算每组成员（连续无姓名间隔的行视为一组）在指定列范围内的总分，并写入总分列（起始列+1）和平均分列（起始列+2）。

### 保存与刷新

- 💾 保存：手动保存当前修改到原文件

- 🔄 刷新表格：重新从工作簿读取数据显示（不会丢失未保存的修改）

## 注意事项

1. Excel 文件的第一列（A列）必须包含学生姓名，且同一组的学生在表格中连续排列（中间无空行）。

2. 程序内部使用拼音首字母映射表，已内置 50 个示例姓名。如需修改或增加，请编辑 init_mp() 中的 name 列表。

3. 分数表达式支持 + 和 - 的连续运算，写入时会自动化简为最简形式（如 100-25-25+2 → 102-50）。

4. 拖拽功能依赖 tkinterdnd2，如无法安装可使用“选择文件”按钮代替。

5. 程序默认不自动保存，点击“保存”按钮后才会写入磁盘。

### 常见问题

- Q: 为什么提示“未安装 tkinterdnd2”？
- A: 拖拽功能需要该库，但不影响其他功能。执行

```bash
pip install tkinterdnd2 
```

即可启用拖拽

- Q: 姓名拼音首字母怎么知道？
- A: 程序内置了 init_mp() 中的姓名列表（约 50 个）。如果你的学生不在列表中，请直接使用中文全名。

- Q: 平均值填充的列范围如何确定？
- A: 打开文件后会弹窗提示输入“起始列 结束列”（如 C L）。程序将统计这两列之间所有列的值并求和，再除以组内人数。
