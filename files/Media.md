# Nick's Media - 多媒体处理工具

## 概述

Nick's Media 是一款功能强大的多媒体处理工具，主要用于图片查看、编辑和处理。该应用基于Python的tkinter和PIL/Pillow库开发，提供了一个直观的图形界面，支持多种图片格式的查看和编辑操作。

## 功能特性

### 1. 图片查看功能
- 支持多种图片格式（JPG, PNG, GIF, BMP, WEBP, TIFF, ICO等）
- 支持图片缩放和平移
- 鼠标滚轮控制缩放
- 拖拽移动图片视图
- 自动适应窗口大小

### 2. 图片编辑功能
- **图片切割**：通过拖拽选择区域进行图片裁剪
- **调整大小**：自定义设置图片宽高，支持锁定纵横比
- **格式转换**：支持转换为多种格式（PNG, JPG, JPEG, BMP, GIF, WEBP, TIFF, ICO），可设置输出质量
- **背景透明化**：选择特定颜色并设置容差值，将其转换为透明区域

### 3. 取色器功能
- **屏幕取色**：实时获取屏幕上任意点的颜色值
- **图片取色**：从加载的图片中选取颜色
- **多种颜色格式**：支持RGB, HEX, HSL, HSV, CMYK格式
- **颜色历史记录**：保存最近使用的20种颜色
- **调色板管理**：支持导出和导入调色板文件
- **快捷键支持**：F2开始取色，ESC停止取色，Ctrl+O打开图片，Ctrl+S保存颜色

### 4. 用户界面特性
- 拖拽支持（需要安装tkinterdnd2）
- 快捷键操作
- 响应式布局
- 实时状态显示
- 文件路径显示

## 使用说明

### 基本操作
1. **打开图片**：
   - 菜单栏：文件 → 打开 (Ctrl+O)
   - 工具栏：点击"打开"按钮
   - 拖拽：直接将图片文件拖拽到应用窗口

2. **图片导航**：
   - 鼠标滚轮：放大/缩小图片
   - 拖拽图片：移动图片视图
   - 右键菜单：快速访问常用功能

### 图片编辑操作
1. **切割图片**：
   - 点击工具栏"切割"按钮
   - 在图片上拖拽选择要保留的区域
   - 松开鼠标完成切割
   - 按ESC键取消切割模式

2. **调整图片大小**：
   - 点击工具栏"重设大小"按钮
   - 输入新的宽度和高度
   - 选择是否锁定纵横比
   - 点击确定完成调整

3. **格式转换**：
   - 点击工具栏"转换格式"按钮
   - 选择目标格式（PNG, JPG, JPEG等）
   - 设置输出质量（1-100）
   - 选择输出目录
   - 点击转换按钮

4. **背景透明化**：
   - 点击工具栏"背景透明"按钮
   - 选择要转换为透明的背景颜色
   - 设置容差值（0-100）
   - 点击预览查看效果
   - 点击应用完成透明化

### 取色器使用
1. **屏幕取色**：
   - 在取色器窗口中选择"屏幕取色"模式
   - 点击"开始取色(F2)"按钮
   - 移动鼠标到需要取色的位置
   - 点击"停止取色(ESC)"结束

2. **图片取色**：
   - 在取色器窗口中选择"图片取色"模式
   - 点击"打开图片文件"加载图片
   - 在预览区域移动鼠标查看颜色值
   - 点击选择特定像素颜色

## 快捷键

| 快捷键 | 功能 |
|--------|------|
| Ctrl+O | 打开文件 |
| Ctrl+S | 保存文件 |
| Ctrl+Shift+S | 另存为 |
| Ctrl+Q | 退出应用 |
| F2 | 开始取色 |
| ESC | 停止取色 |

## 依赖库

- tkinter：GUI框架
- PIL/Pillow：图像处理
- numpy：数值计算（用于透明化功能）
- pyautogui：屏幕取色
- keyboard：热键支持
- tkinterdnd2：拖拽支持（可选）

## 技术特点

1. **多线程处理**：取色功能使用独立线程避免界面卡顿
2. **内存优化**：支持大尺寸图片处理
3. **用户友好**：直观的操作界面和清晰的状态提示
4. **数据持久化**：颜色历史自动保存到本地文件
5. **响应式设计**：窗口大小变化时自动调整内容显示

## 注意事项

1. 拖拽功能需要额外安装tkinterdnd2库
2. 背景透明化后需保存为支持透明度的格式（如PNG）才能保留效果
3. 大尺寸图片处理可能需要较长时间，请耐心等待
4. 格式转换过程中可能会有质量损失，建议保留原图备份
